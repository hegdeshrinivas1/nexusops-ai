2. How the 4 Autonomous Agents Collaborate

        

          

            
01. Supervisor Orchestrator

            
Decomposes broad executive questions into structured sub-tasks spanning quantitative SQL analysis, unstructured policy lookup, and compliance auditing.

          

          

            
02. ReAct SQL Data Analyst

            
Implements the Thought → Action → Observation loop. Inspects database schemas, executes safe read-only queries, and performs automated self-healing reflection if a query fails.

          

          

            
03. Document Specialist (Vector RAG)

            
Executes hybrid semantic cosine search over corporate memos, discount policies, and audit SOPs, citing exact excerpts and similarity scores.

          

          

            
04. Compliance Critic & HITL Gate

            
Cross-references contract discount figures against corporate limits (> 20% threshold), drafts incident tickets in PENDING_APPROVAL status, and waits for human approval.
